# spondere

Spondere é uma proposta de sistema para controle de frequencia acadêmica com uso de reconhecimento facial. O repositório é divido em 3 seçoes principais: [Documentos](/documentos), Servidor e Prototipo.
A [Seção documentos](/documentos) apresnta os documentos de engenharia de software referetes ao planejamento/desenvolvimento do presente projeto, contendo as Subseções: [Documentos de visão](/documentos/Documento_de_visão), [Casos de uso](/documentos/casos_de_uso) e [Diagrama de implantação](/Diagrama_de_implantação).

As demais Seções se encontram em planejamento/desenvolvimento e serao atualizadas em breve.
