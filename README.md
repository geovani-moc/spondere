# spondere

Spondere é uma proposta de sistema para controle de frequencia acadêmica com uso de reconhecimento facial. O repositório é divido em 3 seçoes principais: [Documentos](/documentos), Servidor e Prototipo.
A [Seção documentos](/documentos) apresnta os documentos de engenharia de software referetes ao planejamento/desenvolvimento do presente projeto, contendo as Subseções: [Documentos de visão](/documentos/Documento&#32;de&#32;visão), [Casos de uso](/documentos/casos&#32;de&#32;uso) e [Diagrama de implantação](<https://github.com/geovani-moc/spondere/tree/main/documentos/Diagrama%20de%20implanta%C3%A7%C3%A3o>).

As demais Seções se encontram em planejamento/desenvolvimento e serao atualizadas em breve.
